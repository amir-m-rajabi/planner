# Planner

Planner is a Persian RTL web application for managing daily activities, tracking time, and reviewing daily productivity.

## About

Planner helps users organize their daily activities and keep track of the time they spend on them.

The application is built as a full-stack web project with a vanilla JavaScript frontend, a Node.js/Express backend, and a PostgreSQL database.

## Features

- User registration and login
- User profile
- Timed activities
- Activity sessions with start/stop tracking
- Manual session management
- Untimed activities
- Daily activity records
- Daily notes
- Calendar
- Statistics and reports
- User-specific data
- Persian RTL interface
